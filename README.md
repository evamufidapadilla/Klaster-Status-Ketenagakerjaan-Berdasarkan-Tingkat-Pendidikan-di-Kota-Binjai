# Klaster-Status-Ketenagakerjaan-Berdasarkan-Tingkat-Pendidikan-di-Kota-Binjai
Ketimpangan antara tingkat pendidikan dan status ketenagakerjaan masih menjadi tantangan utama di berbagai daerah di Indonesia, termasuk Kota Binjai. Penelitian ini bertujuan untuk mengelompokkan tingkat pendidikan berdasarkan karakteristik status ketenagakerjaan menggunakan algoritma K-Means.
